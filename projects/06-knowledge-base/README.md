# IT Support Knowledge Base

## Overview

Created step-by-step knowledge base articles for common end-user issues. The goal was to write instructions that are useful to both non-technical users and support technicians without making the articles unnecessarily long.

## Writing Style

Each article follows a simple structure:

1. Problem/symptom
2. Quick checks
3. Step-by-step resolution
4. When to escalate

I avoided filling the articles with theory that an end user would not need. Technician-specific commands are included only where they help isolate the issue.

## Knowledge Management Approach

A useful knowledge article should:

- have a title that matches what users actually report
- start with the safest and quickest checks
- use exact menu names or commands
- explain what result to expect
- include escalation criteria
- avoid assuming administrator permissions
