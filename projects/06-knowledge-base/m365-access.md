# Microsoft 365 Sign-In Troubleshooting

## Problem
User cannot access Outlook, Teams, OneDrive or another Microsoft 365 service.

## Quick Checks
1. Confirm internet connectivity.
2. Confirm the user is signing in with the correct work account.
3. Capture the exact error message.
4. Test the same service in a browser.
5. Check whether other Microsoft 365 services are affected.

## Resolution Path
- Reset the user's password if required and authorised.
- Confirm the account is enabled.
- Review licence assignment.
- Check MFA/authentication method issues.
- Sign out and back in to the affected desktop application.
- Restart the application after account checks.

## Escalate When
- multiple users are affected
- Conditional Access or security policy appears to block access
- the account shows suspicious sign-in activity
- the issue appears tenant-wide
