The labs are built around the kind of work handled by Level 1 / Junior IT Support teams: creating and supporting users, diagnosing connectivity problems, handling access issues, supporting Microsoft 365 applications, troubleshooting Windows endpoints and documenting incidents clearly.

## 1. Windows Server & Active Directory Home Lab

Built a Windows Server virtual lab and configured Active Directory Domain Services for a small-company environment. Created organisational units, users and security groups, joined a Windows client to the domain, managed passwords and locked accounts, configured shared-folder permissions and tested Group Policy.

**Skills:** Active Directory · Windows Server · Group Policy · User Administration · DNS · Permissions

[View project →](projects/01-active-directory/README.md)

## 2. IT Help Desk & Ticketing System Lab

Worked through Level 1 support tickets covering password and account problems, Outlook issues, slow Windows devices, printers, network connectivity and shared-resource access. Each incident includes troubleshooting actions, resolution notes or an escalation decision.

**Skills:** IT Support · Service Desk · Incident Management · Ticketing · Troubleshooting

[View project →](projects/02-help-desk/README.md)

## 3. Microsoft 365 & Entra ID Administration Lab

Completed common Microsoft 365 administration and identity support scenarios including user creation, licence management, password resets, MFA, account access and basic security/access controls.

**Skills:** Microsoft 365 · Microsoft Entra ID · Identity & Access Management · User Administration

[View project →](projects/03-m365-entra/README.md)

## 4. Network Troubleshooting Lab

Diagnosed Windows connectivity issues involving IP addressing, DNS, DHCP and default gateways. Used command-line and PowerShell tools to isolate whether a fault was local, LAN, internet or name-resolution related.

**Skills:** TCP/IP · DNS · DHCP · Network Troubleshooting · Windows

[View project →](projects/04-network-troubleshooting/README.md)

## 5. Windows 11 Endpoint Support Lab

Configured and supported Windows 11 endpoints across user profiles, software installation, Windows Update, devices, security settings and operating-system troubleshooting.

**Skills:** Windows 11 · Desktop Support · Endpoint Management · Software Troubleshooting

## PowerShell Support Toolkit

I also built a small set of read-only diagnostic scripts for first-line support:

- [`Get-SystemHealth.ps1`](scripts/Get-SystemHealth.ps1) — Windows version, uptime, memory, disk and network-adapter state
- [`Test-NetworkConnectivity.ps1`](scripts/Test-NetworkConnectivity.ps1) — layered TCP/IP, gateway, external connectivity and DNS checks
- [`Get-UserSupportSnapshot.ps1`](scripts/Get-UserSupportSnapshot.ps1) — compact device/network snapshot for troubleshooting or escalation
